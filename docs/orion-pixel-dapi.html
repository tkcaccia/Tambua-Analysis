Registered ORION DAPI image pixels

Measured Hoechst fluorescence and GigaTIME virtual DAPI on the same tissue window, alongside registered H&E.

These are image pixels, not cell-table values painted onto masks. The measured channel comes from the released ORION fluorescence OME-TIFF. The virtual DAPI is bilinearly resampled from its 0.25 µm/pixel inference grid to the 0.325 µm/pixel source grid. Display contrast is adjusted independently for inspection; correlations use the saved native signal values. Virtual DAPI remains broader and more saturated than measured nuclei in some fields, so rank agreement must not be read as pixel-exact morphology. This comparison does not validate the other virtual proteins or cell types.

Location is stronger than intensity fidelity. The 0.806 cohort median below includes nuclear and surrounding pixels. Repeating the score within the published registered ORION nuclear masks gives median Spearman 0.174 across the same ten patients (patient-bootstrap 95% interval 0.093–0.250). Nuclear location can agree while brightness rankings among nuclear pixels do not. The compartment-specific native-pixel audit also reports cytoplasm and every patient; it reuses this previously analyzed cohort and is not a new holdout.
