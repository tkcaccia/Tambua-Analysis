# Literature and benchmark choices

This note records how the supplied papers affect Tambua's prospective evaluation. A cited method is **not** a completed Tambua experiment. The public ORION gallery remains a single-patient technical demonstration; its released cell mask is computational, not expert cell-type ground truth.

| Work | What it actually predicts from | Relevance and action |
| --- | --- | --- |
| [Dayao et al., *Cell Reports Methods* 2025](https://doi.org/10.1016/j.crmeth.2025.101204) | H&E cell patches; cell-type training targets derived from paired CODEX. Compares a foundation-embedding classifier, contrastive model and H&E CNN across kidney cohorts. | **Closest conceptual prior art for Tambua's H&E-to-cell-type claim.** Cite it explicitly and compare on a shared cohort only if its CODEX-derived target labels, cell instances, split and ontology can be reproduced. Its reported cross-dataset weighted F1 (0.314 for the embedding classifier) is not a Tambua score or a directly comparable MoNuSAC result. Public [TWMU-TR](https://doi.org/10.5281/zenodo.16938687) and [Stanford-TR](https://doi.org/10.5281/zenodo.16938814) data are a future external-domain experiment; inspect storage and patient identifiers before acquisition. |
| [CellViT++, *Computer Methods and Programs in Biomedicine* 2026](https://doi.org/10.1016/j.cmpb.2025.109206) and [CellViT, *Medical Image Analysis* 2024](https://doi.org/10.1016/j.media.2024.103143) | H&E nuclear instances and types. CellViT++ uses a frozen segmentation backbone and a lightweight classifier on cell embeddings. | Direct **end-to-end H&E instance/type comparator**. Preserve checkpoint and taxonomy provenance; resample according to measured pixel spacing (CellViT++ commonly evaluates at 0.25 µm/pixel). Do not silently equate PanNuke types with MoNuSAC types. |
| [HoVer-Net, *Medical Image Analysis* 2019](https://doi.org/10.1016/j.media.2019.101563) | H&E nuclear instances and types. | Direct end-to-end comparator. Use the MoNuSAC checkpoint for the proposed official MoNuSAC test split and audit its training patients. [CoNSeP](https://warwick.ac.uk/fac/sci/dcs/research/tia/data/hovernet/) is a useful **second expert-annotated colorectal test** if a patient-disjoint checkpoint and a prospectively fixed class mapping are available. Avoid testing a CoNSeP-trained checkpoint on the same CoNSeP images. |
| [Nimbus, *Nature Methods* 2025](https://doi.org/10.1038/s41592-025-02826-9) | **Measured multiplex channels** and segmented cells; predicts marker positivity. | Useful benchmark for per-cell marker positivity when measured ORION/other paired fluorescence exists. It is not a same-input H&E-only baseline. Test whether Tambua's virtual marker positivity agrees with measured-marker references before relying on a marker for classification. |
| [Pixie, *Nature Communications* 2023](https://doi.org/10.1038/s41467-023-40068-5) | Measured multiplex pixels; clusters cellular and spatial phenotypes. | Motivates adding nuclear, cytoplasmic, membrane and neighborhood summaries, alongside whole-cell means, in an **ablation** of virtual-marker quantification. These regions need verified masks and registered measurements. Pixie is not a direct H&E-only comparator. |
| [PathoPlex, *Nature* 2025](https://doi.org/10.1038/s41586-025-09225-2) | High-resolution measured multiplex imaging. | A potential measured-protein reference or robustness dataset after checking paired H&E, pixel scale, masks and permitted use. Its protein measurements are not virtual H&E predictions. |
| [histoCAT, bioRxiv 2017](https://doi.org/10.1101/109207) | Measured multiplex single-cell features and spatial neighborhoods. | Foundational precedent for spatial cell-phenotype analysis, not a like-for-like Tambua classifier baseline. |

## Frozen evaluation path

1. Use the original **MoNuSAC test archive** for the primary expert instance/type endpoint. Its 101 `.svs` ROI headers and paired XML agree on 0.2456–0.2527 µm/pixel, unlike the third-party mirror with unverified spacing. Record the patient split, exact four-class mapping, source checksum and all resampling transforms. Neither a technical ORION field nor virtual DAPI overlap substitutes for this expert test.
2. Fit the fastPLS 0.4 cell-type model only on training patients. Freeze GigaTIME, segmentation, feature definitions, thresholds and competitor checkpoint/type mappings before examining test scores. First report matched-instance type scores and end-to-end detection/type scores as different endpoints.
3. Run CellViT++ and HoVer-Net on the **same calibrated images**. Report each method's native types and the fixed common ontology, plus detection F1, class-wise F1, macro F1, runtime and memory. Audit test overlap with the selected pretrained checkpoints. Any one-field ORION outputs are visualization and handoff evidence only.
4. If feasible, add CoNSeP as a colorectal external-domain expert test. The Dayao kidney cohorts answer a different but important question: whether a cell-type predictor transfers across paired H&E/multiplex cohorts. Their CODEX-derived labels are not an independent expert reference and should be reported separately from MoNuSAC/CoNSeP.
5. On a paired H&E/multiplex cohort, quantify virtual-versus-measured marker agreement and predefine a DAPI morphology QC gate. Avoid assuming a biologically useful marker solely because it appears plausible in a preview. Analyze uncommon cell types and patient-level uncertainty separately.

No additional dataset or comparator has been scored as a result of reading these papers. Acquisition and evaluation must be recorded with their own provenance and result files before the public site presents a score.
