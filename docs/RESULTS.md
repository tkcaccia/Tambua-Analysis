# Calibrated ORION image result

The [results gallery](https://tkcaccia.github.io/Tambua-Analysis/) contains three fixed fields from one ORION CRC33_01 registered H&E window. Each field shows H&E, cyan contours of the released **computational** cell mask, GigaTIME DAPI over H&E, and the virtual DAPI, CK, CD3 and CD68 channels. The released mask was made by the ORION image-processing pipeline; it is **not** an expert-drawn cell-type annotation. It is used here for a spatial and identity handoff check only. The [ORION release](https://github.com/labsyspharm/orion-crc/blob/main/README.md) documents its registered images and generated masks.

The source field is 2048 × 2048 pixels, with OME metadata of 0.325 µm/pixel. CellPhenotyper resampled this exact physical field to 2663 × 2663 at 0.25 µm/pixel for GigaTIME CNN inference. The model snapshot is `a6556030bdb8071857559e12b921620aa1bbac5b` and the checkpoint SHA-256 is `d200308302c7fefd13b259c62de546f2c859c28d1079e9f67dc8808915d95d0c`. The [GigaTIME authors' geometry clarification](https://github.com/prov-gigatime/GigaTIME/issues/4) supports the 0.25 µm/pixel model grid.

The generated table contains exactly 4,104 positive cell IDs, all matching the published mask and measured-cell table, with no missing virtual-marker values. Twenty-three virtual channels are present and all scores are within 0–1. These are **uncalibrated virtual scores**, not measured protein concentrations or calibrated probabilities. The four preview JPEGs and table were generated in one bounded Chiamaka GPU case, with exit code 0 and no owned process or GPU compute context after completion.

The saved H&E/DAPI overlay was visually reviewed and DAPI signal coincided with many hematoxylin-stained nuclei. Among pixels inside published cell regions, the upper-quartile DAPI and hematoxylin signals overlapped in 381,114 pixels versus 184,256.9 expected under pixelwise independence, an enrichment of **2.068**. This is a morphological plausibility check; it is not expert nuclear-mask Dice. The original ORION dataset's registered H&E, published cell mask and measured-cell table can be reacquired via the [first-party release index](https://github.com/labsyspharm/orion-crc/blob/main/datarelease-README.md).

Within this single case, cell-level Spearman correlations between GigaTIME and ORION measured markers ranged from 0.599 for DAPI/Hoechst to −0.160 for CD20/CD20. The associations are stored in [machine-readable form](assets/orion-crc33-01/marker-associations.json) and reproduced with [`analysis/score_virtual_markers.py`](../analysis/score_virtual_markers.py). This evidence cautions against assuming every virtual channel is a reliable classifier input; it supplies no independent-patient cell-type accuracy estimate.

Two separately authorized CellViT++/HoVer-Net comparison bundles stopped before inference. In the first, the CellViT++ container lacked `pyvips` during image preparation. After a CPU-validated isolated overlay and new authorization, the second progressed to the CellViT++ reader, which rejected the temporary TIFF because its magnification metadata was absent. Both recorded CellViT++ exit code 1, verified that their owned process groups and GPU compute contexts were gone, and stopped before HoVer-Net. Neither bundle was retried. Consequently, **there are no matched baseline masks or scores to publish yet**. The website does not invent them. A biological comparison requires a calibrated, expert-typed test cohort with frozen patient-disjoint Tambua training, a fixed CellViT++ type mapping, and both baselines run on identical images. ORION's computational mask cannot be called expert annotation.

The [training-data provenance audit](DATA_PROVENANCE.md) distinguishes GigaTIME's published 21 in-house lung-adenocarcinoma training slides from this ORION colorectal technical case and the proposed MoNuSAC expert test set. Neither selected source is reported as part of the GigaTIME translator training set. Exact sample-level exclusion for MoNuSAC requires the original training slide manifest, which is not published in the cited paper.
