HEMIT: measured versus virtual markers

Independent same-section colorectal H&E and multiplex-IHC image pairs. Inspect all 287 eligible, nonoverlapping official-test images.

Interpretation. GigaTIME localizes DAPI-associated nuclei well on this second dataset, but agreement for CD3 and Pan-CK is substantially weaker. A passing nuclear or border-seam check does not validate virtual proteins for cell typing. This gallery evaluates image-level marker localization, not Tambua cell-type classification.

Measured and predicted localization

The fixed GigaTIME CNN receives the released H&E at a literature-reported 0.25 µm/pixel and produces weighted, overlapping predictions without visible tile seams in the technical check. HEMIT target TIFF bands are Pan-CK (red), CD3 (green), and DAPI (blue). The source TIFFs themselves lack usable pixel-size tags; the 0.25 µm/pixel calibration comes from an independent HEMIT report. Each comparison image uses independent display contrast for the measured channel, while scores use the native released pixels and model probabilities.
