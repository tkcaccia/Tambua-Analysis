Registered ORION measured-marker images

Raw fluorescence windows from ten QC-passing patients, shown with the registered H&E.

Measured-source inspection only. These are ten actual ORION fluorescence channels, not GigaTIME predictions or per-cell values painted onto masks. All 100 uint16 images were checked against their source hashes, 0.325 µm/pixel spacing and registered coordinates. Each panel uses its own display contrast; brightness across panels is not a quantitative comparison. The saved virtual images currently cover DAPI alone. See the measured-versus-virtual DAPI viewer for the valid paired spatial comparison.

Panel order: H&E, Hoechst, CD68, CD4, CD8a, CD20, PD-L1, CD3e, PD-1, Ki67, Pan-CK. Read the verified source and calibration manifest. The contact sheets were visually reviewed for registered tissue patterns and obvious acquisition faults; they do not validate virtual-marker accuracy.
