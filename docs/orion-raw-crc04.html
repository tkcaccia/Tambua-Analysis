This field is excluded from protein-validity and cell-type accuracy claims. It is shown so the failure is inspectable.

Native spatial images. The measured panels are the released ORION fluorescence pixels, and the virtual panels are saved GigaTIME spatial output resampled onto the H&E grid. They are not cell-table values painted onto masks. Display contrast is adjusted separately for viewing; the reported rank associations use native values within tissue pixels. The scanner image is RGB. Both source and model spacing are recorded for every image.
